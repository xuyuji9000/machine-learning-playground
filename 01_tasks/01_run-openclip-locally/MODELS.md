## Usage

```shell
# explicit pair:
clip_benchmark eval --model ViT-L-14 --pretrained openai ...
# combined form:
clip_benchmark eval --pretrained_model 'ViT-L-14,openai' ...
# collections (predefined lists):
clip_benchmark eval --pretrained_model openai ...          # OpenAI's 8 models
clip_benchmark eval --pretrained_model openclip_base ...   # common base set
clip_benchmark eval --pretrained_model openclip_all ...    # everything below
```
